## Grid Trading

Grid trading works by the simple strategy of buy low and sell high. 
After you set the parameters, the system automatically places orders at incrementally increasing or decreasing prices. Overall, the grid bot seeks to capitalize on normal price volatility by placing buy and sell orders at certain regular intervals above and below a predefined base price.<br>
The API endpoints of `Grid Trading` require authentication.
