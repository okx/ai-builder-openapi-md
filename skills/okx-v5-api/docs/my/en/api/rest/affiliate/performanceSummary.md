<a id="affiliate-rest-api-get-performance-summary"></a>### Get CPS performance summary

The data in this section applies to affiliate accounts using the CPS incentive model. Under CPS (Cost Per Sale), affiliates earn rewards based on eligible trading fees generated by invitees sourced from applicable jurisdictions. This endpoint returns an overall summary of the affiliate account’s performance under the CPS model.

#### Rate Limit: 3 requests per second
#### Rate limit rule: User ID
#### HTTP Request

`GET /api/v5/affiliate/performance/summary`

> Request Example

```shell
GET /api/v5/affiliate/performance/summary?periodType=total
```

#### Request Parameters

| **Parameter** | **Type** | **Required** | **Description** |
| :------------ | :------- | :----------- | :-------------- |
| periodType    | String   | No           | Stats window for all summary fields except `uTime`.<br>`last_7d`<br>`last_30d`<br>`this_month`<br>`last_month`<br>`total`<br>`today`<br>`this_week`<br>`custom`: pass `begin` and `end` to define a custom window.<br>The default is `total`. |
| begin         | String   | Conditional  | Custom stats-window start, Unix timestamp in millisecond format. Required when `periodType=custom`, together with `end`. Inclusive. |
| end           | String   | Conditional  | Custom stats-window end, Unix timestamp in millisecond format. Required when `periodType=custom`, together with `begin`. Inclusive. |

When `periodType=custom`, supply both `begin` and `end`. Supplying only one returns `50014`.<br>
For all other `periodType` values, server-defined windows are used and any `begin` / `end` passed alongside are ignored.<br>
`periodType` / `begin` / `end` filter the statistics window for all summary fields (`inviteeCnt`, `depAmt`, `details.*`). `uTime` always reflects the latest data snapshot regardless of the window.

#### Response Parameters

| **Parameter**        | **Type**         | **Description** | **Data scope** |
| :------------------- | :--------------- | :-------------- | :------------- |
| uTime                | String           | Last data update timestamp, Unix timestamp in millisecond format. |
| inviteeCnt           | String           | Total number of invitees. | CPS+TVB both |
| depAmt               | String           | Total deposit amount, unit in `USDC`. | CPS+TVB both |
| details              | Array of objects | One entry per instrument bucket. |
| > commissionCategory | String           | Commission calculation category.<br>`SPOT`<br>`DERIVATIVE`<br>Derivative commission from OKX users in the EEA is not applicable due to regulatory requirements. Spot and derivative commissions from eligible regions remain fully applicable. |
| > firstTraderCnt     | String           | Number of invitees who completed their first trade after joining or rejoining the affiliate's invitation relationship during the selected period. Reported separately for SPOT and DERIVATIVE. Only a trade that generated eligible commission is counted; a trade that generates no commission is not included.<br><br>CPS firstTraderCnt counts invitees whose first trade occurred after they joined or rejoined the affiliate's invitation relationship, within the selected period, and only where that trade generated eligible commission. TVB validFirstTraderCnt is based on eligible trading volume and does not require commission to have been generated. For the same invitees, the CPS count is therefore systematically lower than the TVB count. The two are not comparable. | CPS+TVB both |
| > traderCnt          | String           | Number of distinct invitees who traded in the selected period, reported separately for SPOT and DERIVATIVE. An invitee may appear in more than one category. | CPS+TVB both |
| > vol                | String           | Total trading volume generated by the affiliate's invitees during the selected period, reported separately for SPOT and DERIVATIVE. This is general trading volume, not valid or eligible. | CPS+TVB both |
| > commission         | String           | Commission earned in this `commissionCategory` bucket within the selected window, unit in `USDC`. Period-scoped — distinct from `totalCommission` on other endpoints which is lifetime cumulative. | CPS only |
