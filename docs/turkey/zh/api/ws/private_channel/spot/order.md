### WS / 订单频道 [order-book-trading-trade-ws-order-channel]

<aside class="notice">
该频道为私有频道，需验证后使用
</aside>

获取订单信息，首次订阅不推送，只有当下单、撤单等事件触发时，推送数据

#### 服务地址

/ws/v5/private (需要登录)

> 请求示例：

```shell
{
    "id": "1512",
	"op": "subscribe",
	"args": [{
		"channel": "orders",
		"instType": "ANY"
	}]
}
```

#### 请求参数

| 参数           | 类型   | 是否必须        | 描述                                 |
|:-------------| :----- |-------------|:-----------------------------------|
| id     | String | 否       | 消息的唯一标识。<br>用户提供，返回参数中会返回以便于找到相应的请求。<br>字母（区分大小写）与数字的组合，可以是纯字母、纯数字且长度必须要在1-32位之间。 |
| op           | String | 是           | 操作<br>`subscribe`<br>`unsubscribe` |
| args         | Array of objects  | 是           | 请求订阅的频道列表                          |
| > channel    | String | 是           | 频道名<br>`orders`                    |
| > instType   | String | 是           | 产品类型<br>`ANY`：全部                   |
| > instId     | String | 否           | 产品ID                               |

> 成功返回示例：

```json
{
    "id": "1512",
	"event": "subscribe",
	"arg": {
		"channel": "orders",
		"instType": "ANY"
	},
    "connId": "a4d3ae55"
}
```

> 失败返回示例

```json
{
    "id": "1512",
	"event": "error",
	"code": "60012",
	"msg": "Invalid request: {\"op\": \"subscribe\", \"argss\":[{ \"channel\" : \"orders\", \"instType\" : \"FUTURES\"}]}",
    "connId": "a4d3ae55"
}
```
#### 返回参数

| 参数         | 类型       | 是否必须 | 描述                                                                                             |
|:-----------|:---------|------|:-----------------------------------------------------------------------------------------------|
| id     | String | 否       | 消息的唯一标识                                                                                           |
| event      | String   | 是    | 事件<br>`subscribe`<br>`unsubscribe`<br>`error`                                                  |
| arg        | Object   | 否    | 订阅的频道                                                                                          |
| > channel  | String   | 是    | 频道名                                                                                            |
| > instType | String   | 是    | 产品类型<br>`ANY`：全部                                                                               |
| > instId   | String   | 否    | 产品ID                                                                                           |
| code       | String   | 否    | 错误码                                                                                            |
| msg        | String   | 否    | 错误消息                                                                                           |
| connId     | String   | 是    | WebSocket连接ID                                                                                  |
