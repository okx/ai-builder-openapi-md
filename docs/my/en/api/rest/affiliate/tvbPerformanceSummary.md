### Get TVB performance summary

The data in this section applies to affiliate accounts using the TVB incentive model. Under TVB (Trading Volume Bonus), rewards are calculated based on eligible trading volume generated by invitees sourced from applicable jurisdictions. This endpoint returns an overall summary of the affiliate account's performance under the TVB model.

#### Rate Limit: 3 requests per second
#### Rate limit rule: User ID
#### HTTP Request

`GET /api/v5/affiliate/tvb/performance/summary`

> Request Example

```shell
GET /api/v5/affiliate/tvb/performance/summary?periodType=last_30d
```

#### Request Parameters

| **Parameter** | **Type** | **Required** | **Description** |
| :------------ | :------- | :----------- | :-------------- |
| periodType    | String   | No           | Stats window for the metric fields.<br>`last_7d`<br>`last_30d`<br>`this_month`<br>`last_month`<br>`this_week`<br>`today`<br>`total`<br>`custom`: pass `begin` and `end` to define a custom window.<br>The default is `total`. |
| begin         | String   | Conditional  | Custom stats-window start, Unix timestamp in millisecond format. Required when `periodType=custom`, together with `end`. Inclusive. Used for a custom window — `periodType=custom`, or `periodType` omitted with both `begin` and `end` supplied. |
| end           | String   | Conditional  | Custom stats-window end, Unix timestamp in millisecond format. Required when `periodType=custom`, together with `begin`. Inclusive. Used for a custom window — `periodType=custom`, or `periodType` omitted with both `begin` and `end` supplied. |

When `periodType=custom`, supply both `begin` and `end`. Supplying only one returns `50014`.<br>
For all other `periodType` values, server-defined windows are used and any `begin` / `end` passed alongside are ignored.<br>
When `periodType` is omitted, the window falls back to `custom` if both `begin` and `end` are present, otherwise `total`.<br>
A custom window (`end − begin`) must be between 1 and 90 days.<br>
`begin` must not be earlier than 180 days ago — data is available only for the past 180 days.<br>
`multiplier`, `ccy` and `uTime` are not window-scoped — they reflect the current config / data snapshot regardless of `periodType`.

#### Response Parameters

| **Parameter**          | **Type** | **Description** | **Data scope** |
| :--------------------- | :------- | :-------------- | :------------- |
| tradingVolBonus        | String   | Accrued TVB bonus in the selected window, unit in `USDC`. Accrued value — includes amounts still pending/suspended. Includes amounts that are still pending or suspended and may not equal the amount paid. | TVB only |
| validVol               | String   | Valid trading volume in the selected window — trading volume from valid invitees, unit in `USDC`. | TVB only |
| eligibleVol            | String   | Eligible trading volume — the subset of valid volume that generates the bonus (bonus base), unit in `USDC`. | TVB only |
| validInviteeCnt        | String   | Distinct valid invitees in the selected window. Valid = users with an active invite relationship to this affiliate. | CPS+TVB both |
| validTraderCnt         | String   | Distinct valid invitees who traded in the selected window. | TVB only |
| eligibleTraderCnt      | String   | Distinct traders who traded and generated bonus (subset of `validTraderCnt`). | TVB only |
| validDepAmt            | String   | Deposit from valid invitees in the selected window, unit in `USDC`. | CPS+TVB both |
| validFirstTraderCnt    | String   | Distinct valid invitees whose first-ever trade occurred within the selected window (FTT). Each invitee is counted at most once.<br><br>CPS firstTraderCnt counts invitees whose first trade occurred after they joined or rejoined the affiliate's invitation relationship, within the selected period, and only where that trade generated eligible commission. TVB validFirstTraderCnt is based on eligible trading volume and does not require commission to have been generated. For the same invitees, the CPS count is therefore systematically lower than the TVB count. The two are not comparable. | TVB only |
| validFirstDepositorCnt | String   | Distinct valid invitees whose first-ever deposit occurred within the selected window (FTD). Each invitee is counted at most once. | TVB only |
| multiplier             | String   | Affiliate's current bonus multiplier as a decimal ratio, e.g. `0.5` = 50%. Not window-scoped. |
| ccy                    | String   | Settlement currency. Constant `USDC`. |
| uTime                  | String   | Last data update timestamp, Unix timestamp in millisecond format. Returns `""` when no data is available yet. |
