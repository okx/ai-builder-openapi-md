# Affiliate 

The Affiliate Program supports two incentive models in Europe, subject to jurisdictional availability: a commission-based model (CPS, Cost Per Sale) and a trading volume-based model (TVB).

Under the CPS model, rewards are calculated based on eligible trading fees generated by invitees sourced from applicable jurisdictions. Under the TVB model, rewards are calculated based on eligible trading volume sourced from applicable jurisdictions. The TVB model is not applicable to Spain, the Netherlands, or Malta.

Before using the Affiliate API, affiliates should confirm which incentive model applies to their account. Data under the CPS and TVB models is calculated separately and should not be aggregated.

## Field coverage by incentive model

Fields returned by the Affiliate APIs fall into two categories:

- Model-specific fields represent rewards accrued under one model only.
  commission, totalCommission, commission24h, totalFee and accFee are returned
  under the CPS model. tradingVolBonus, validVol, eligibleVol, bonusRate and
  multiplier are returned under the TVB model.

- Shared fields describe invitee activity — invitee counts, deposits, traders
  and trading volume — and reflect that activity under the definitions of the
  endpoint being called.

Because shared fields may describe the same underlying invitees, values returned
by CPS endpoints and TVB endpoints must not be added together. Each endpoint
should be read as a self-contained view of the affiliate account under one
incentive model.

CPS endpoints use the /api/v5/affiliate/… paths; TVB endpoints use the
/api/v5/affiliate/tvb/… prefix.

| API name | Path | Incentive model |
| --- | --- | --- |
| Get CPS performance summary | `/api/v5/affiliate/performance/summary` | CPS |
| Get CPS invitee detail | `/api/v5/affiliate/invitee/detail` | CPS |
| Get CPS invitee list | `/api/v5/affiliate/invitee/list` | CPS |
| Get CPS link list | `/api/v5/affiliate/link/list` | CPS |
| Get TVB performance summary | `/api/v5/affiliate/tvb/performance/summary` | TVB |
| Get TVB bonus breakdown by fee tier | `/api/v5/affiliate/tvb/tier-breakdown` | TVB |
| Get TVB invitee list | `/api/v5/affiliate/tvb/invitee/list` | TVB |
| Get TVB invitee detail | `/api/v5/affiliate/tvb/invitee/detail` | TVB |
| Get TVB link list | `/api/v5/affiliate/tvb/link/list` | TVB |
