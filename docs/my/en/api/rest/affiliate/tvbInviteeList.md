### Get TVB invitee list

The data in this section applies to affiliate accounts using the TVB incentive model. Under TVB (Trading Volume Bonus), rewards are calculated based on eligible trading volume generated by invitees sourced from applicable jurisdictions. This endpoint returns a list of users attributed to the affiliate account under the TVB model.

#### Rate Limit: 3 requests per second
#### Rate limit rule: User ID
#### HTTP Request

`GET /api/v5/affiliate/tvb/invitee/list`

> Request Example

```shell
GET /api/v5/affiliate/tvb/invitee/list?periodType=last_30d&page=1&limit=100
```

#### Request Parameters

| **Parameter** | **Type**          | **Required** | **Description** |
| :------------ | :---------------- | :----------- | :-------------- |
| periodType    | String            | No           | Stats window for the metric fields.<br>`last_7d`<br>`last_30d`<br>`this_month`<br>`last_month`<br>`this_week`<br>`today`<br>`total`<br>`custom`: pass `begin` and `end` to define a custom window.<br>The default is `total`.<br>The window scopes the metric fields (`validVol` / `eligibleVol` / `validDepAmt` and the summary aggregates) by activity time; it does not affect which invitees are returned — the invitee set is determined by `feeTier` / `keyword`. These summary aggregates cover the entire filtered result set and do not change across pages. |
| begin         | String            | Conditional  | Custom stats-window start, Unix timestamp in millisecond format. Required when `periodType=custom`, together with `end`. Inclusive. Used for a custom window — `periodType=custom`, or `periodType` omitted with both `begin` and `end` supplied. |
| end           | String            | Conditional  | Custom stats-window end, Unix timestamp in millisecond format. Required when `periodType=custom`, together with `begin`. Inclusive. Used for a custom window — `periodType=custom`, or `periodType` omitted with both `begin` and `end` supplied. |
| feeTier       | Array of strings  | No           | Filter by invitee fee-tier code(s): `0` = Regular, `10`–`18` = VIP1–VIP9. Numeric only. This request filter is distinct from the response `level` field, which returns a display name — see the response note. |
| tradeType     | String            | No           | Trade product type for the volume metrics (selects which product's amounts to read, not which invitees).<br>`ALL`<br>`SPOT`<br>`DERIVATIVE`<br>`BSC`<br>The default is `ALL`. |
| keyword       | String            | No           | Search invitees by UID. |
| orderBy       | String            | No           | Sort field.<br>`joinTime`<br>`validDepAmt`<br>`validVol`<br>The default is `joinTime`. |
| orderDir      | String            | No           | Sort order.<br>`asc`<br>`desc`<br>The default is `desc`. |
| page          | String            | No           | 1-indexed page number. Non-numeric values fall back to `1`. The default is `1`. |
| limit         | String            | No           | Items per page. Clamped to `[1, 100]`. The default is `100`. |

Custom-window rules match the summary endpoint: `periodType=custom` requires both `begin` and `end`; the window (`end − begin`) must be between 1 and 90 days; `begin` must not be earlier than 180 days ago. Otherwise `50076`.<br>
The request filter `feeTier` takes numeric code(s) (`0`, `10`–`18`), while the response returns the localized display name in the `level` field (`VIP 1`).<br>
`validDepAmt` is masked to `""` for callers lacking the deposit-view permission, same discipline as invitee detail.<br>
`orderBy` / `orderDir` apply per request — pass them on every page call to keep ordering stable across pages. Changing the sort between page requests produces unspecified ordering (possible duplicates or gaps).<br>
No per-invitee bonus is exposed.

#### Response Parameters

| **Parameter**       | **Type**         | **Description** | **Data scope** |
| :------------------ | :--------------- | :-------------- | :------------- |
| totalPage           | String           | Total number of pages under the current filters and `limit`. Same level as `data` in the response. |
| tradingVolBonus     | String           | Accrued TVB bonus in the selected window, unit in `USDC`. Accrued value — includes amounts still pending/suspended. Includes amounts that are still pending or suspended and may not equal the amount paid. | TVB only |
| validVol            | String           | Valid trading volume in the selected window — trading volume from valid invitees, unit in `USDC`. | TVB only |
| eligibleVol         | String           | Eligible trading volume — the subset of valid volume that generates the bonus (bonus base), unit in `USDC`. | TVB only |
| validDepAmt         | String           | Deposit from valid invitees in the selected window, unit in `USDC`. | CPS+TVB both |
| validInviteeCnt     | String           | Distinct valid invitees in the selected window. Valid = users with an active invite relationship to this affiliate. | CPS+TVB both |
| validFirstTraderCnt | String           | Distinct valid invitees whose first-ever trade occurred within the selected window (FTT). Each invitee is counted at most once. | TVB only |
| validTraderCnt      | String           | Distinct valid invitees who traded in the selected window. | TVB only |
| eligibleTraderCnt   | String           | Distinct traders who traded and generated bonus (subset of `validTraderCnt`). | TVB only |
| invitees            | Array of objects | The result rows. The same `uid` may repeat — one row per fee-tier segment held in the window, with `level` and amounts scoped to that segment. |
| > uid               | String           | The invitee's UID. |
| > joinTime          | String           | Time the invite relationship was established, Unix timestamp in millisecond format. |
| > country           | String           | Invitee's country / region. |
| > kycTime           | String           | KYC verification time, Unix timestamp in millisecond format. Returns `""` when not verified. |
| > affiliateCode     | String           | The affiliate invite code the invitee registered via. |
| > firstTradeTime    | String           | First trade time after the relationship was established, Unix timestamp in millisecond format. Returns `""` when not traded. |
| > level             | String           | Invitee's trading fee tier display name, e.g. `Regular User`, `VIP 1`–`VIP 9`. This is the localized display name, NOT the numeric code taken by the request `feeTier` filter — do not pass it back as a filter value. |
| > validVol          | String           | Trading volume in the window, unit in `USDC`. | TVB only |
| > eligibleVol       | String           | Eligible (bonus-generating) trading volume in the window, unit in `USDC`. | TVB only |
| > validDepAmt       | String           | Invitee's deposit in the window, unit in `USDC`. Returns `""` for callers without deposit-view permission (masked). | CPS+TVB both |
| > note              | String           | Affiliate's private note/remark on this invitee. Returns `""` when none. |
